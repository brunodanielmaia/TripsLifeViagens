Projeto da StartUp Trips Life

## Deployment

This application is ready to be deployed to Heroku. To deploy this application, follow these steps:

1.  **Create a Heroku app:**
    ```bash
    heroku create
    ```

2.  **Push the code to Heroku:**
    ```bash
    git push heroku main
    ```

3.  **Open the app in your browser:**
    ```bash
    heroku open
    ```
